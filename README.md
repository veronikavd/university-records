# 🏆 University Records System (Книга Рекордів Університету)

Веб-платформа для фіксації, збереження та аналізу досягнень студентів університету. Система поєднує в собі облік академічних, спортивних та творчих успіхів з елементами гейміфікації.

## 🚀 Основний Функціонал

### 👤 Для Студентів
* **Особистий кабінет:** Перегляд історії власних досягнень та статусу заявок.
* **Подача рекордів:** Завантаження доказів у форматах зображень (JPG/PNG) або документів (PDF).
* **Гейміфікація:** Автоматичне отримання бейджів ("Дебют", "Активіст", "Гордість факультету") при досягненні певної кількості схвалених рекордів.
* **QR-Сертифікати:** Генерація унікального QR-коду для кожного підтвердженого рекорду, який веде на сторінку досягнення.

### 🛡 Для Адміністраторів
* **Панель керування (Dashboard):** Зручний інтерфейс для модерації контенту.
* **Модерація заявок:** Можливість схвалювати (`Approved`) або відхиляти (`Rejected`) заявки студентів.
* **Керування категоріями:** Додавання нових категорій та **безпечне видалення** (система не дозволяє видалити категорію, якщо в ній є активні записи).
* **Аналітика:** * Графік розподілу рекордів по категоріях (Doughnut Chart).
  * Динаміка активності подання заявок (Line Chart).
  * Рейтинги топ-студентів та найактивніших груп.

## 🛠 Технологічний Стек

* **Backend:** Python 3, Flask, Flask-SQLAlchemy (ORM), Flask-Login, Flask-Migrate.
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (Chart.js).
* **Tools:** * `Pillow` & `qrcode` — для обробки зображень.
  * `Werkzeug` — для безпечного хешування паролів та імен файлів.

## ⚙️ Інструкція із запуску (Local Setup)

Щоб розгорнути проєкт на локальній машині, виконайте наступні кроки:

### 1. Клонування репозиторію
```bash
git clone [https://github.com/YOUR-USERNAME/university-records.git](https://github.com/YOUR-USERNAME/university-records.git)
cd university-records

3. Встановлення залежностей
Bash
pip install -r requirements.txt

4. Налаштування бази даних
Ініціалізація та створення таблиць:

Bash
flask db upgrade

5. Запуск сервера
Bash
flask run

Додаток буде доступний за адресою: http://127.0.0.1:5000
